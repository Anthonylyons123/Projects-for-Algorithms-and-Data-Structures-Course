
This repository contains a series of projects from a Data Structures and Algorithms course. Each project builds on the previous one, reusing existing classes and functions to demonstrate how different data structures can be applied to the same dataset.

**Project Overview**

**P1 – Single Node**
Reads one line of data from a text file and stores it in a single node.

**P2 – Linked List**
Reads every line of the text file and constructs a linked list.

**P3 – Binary Search Tree**
Uses data stored in the linked list to build a binary search tree.

**P4 – Hash Table**
Implements a hash table using the same data as P3, highlighting the faster runtime of hashing compared to searching a tree.

**P5 – Graph**
Constructs a graph by comparing similar data within nodes of the linked list.
